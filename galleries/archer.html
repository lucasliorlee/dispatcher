Skin Trivia

  • The first version of the Huntsman skin was made by impjelly.
  • The first version of the Default skin wore the Christmas Beanie and Christmas Coat from R2DA at Level 5.
  • Oddly, some renders depicted the Default Holiday Archer with an eyepatch, when it is not present on the actual tower.
    • This is because the original model actually had an eyepatch, though this part of the design was cut before release.
  • When the Overhaul Update was released, no skins were successfully carried over from the previous version of the game.
    • This was fixed on the 23rd of November 2020.
  • The Archer used to share its Level 3 icon with the Gladiator's Level 2 icon.
  • The Ninja skin was made by Tixlord.
  • The Archer's Level 5 upgrade icon used to be a sword, despite the Archer not having a sword or a melee attack at all.
    • This is because the Archer's Level 5 upgrade name used to be called Sword Arrows, which is why the icon used a sword. Despite this, the arrows for the Archer did not change into sword arrows.
  • The first version of the Valentines skin was based on 7ess' concept art of it, the latter being a friend of MRhello.
    • The original name of the concept art skin was called the Love Messenger.
  • The Elf skin is based on the first version of the Default skin.
  • The Ice Soul is a submission made by linxthedeveloper.
    • This skin was first submitted in 2023, before getting added during the The Final Act Event in the Christmas 2025 Crate.

Roblox Catalog

  • The first version of the Huntsman skin used a hat similar to the Bear Hunter accessory from the Roblox catalog.
  • The first version of the Default skin used a re-textured version of the Elf Hat accessory from the Roblox catalog.
  • The headband used by the Ninja skin was the Black Ninja Headband of the Silent Sun accessory from the Roblox catalog.
  • The sword on the Level 5 upgrade icon is the Spartan Sword gear from the Roblox catalog.

This only refers to cosmetic changes to the Archer. Check the main article for statistical changes.
