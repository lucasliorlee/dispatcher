Description

Slime is a status effect that summons a Slime enemy when the enemy with the attribute is killed.

Mechanics

Slime attribute makes it so that any enemy with it spawns a Slime upon death. While the Slime is spawned upon death, it is not considered a summoned enemy, which can be seen by it not having the enemy's name at the start of its name. This means that it can have cash generated from itself and it counts for Cowboy's cash shot, unlike all other summoned enemies.

Additionally, the Slime itself has this attribute, but it does make it summon a Slime on death. Instead, having the Slime attribute will activate its Slimy Disguise ability. If the Slime does not have the Slime attribute, it is completely unable to use it.

Due to a bug, the Ghoul, Reaver and Living Experiment do not spawn the Slime upon death if they have the Slime attribute.

Enemy List

The following enemies can spawn with Slime, but do not have it by default:

  • Shadow (Jailed Towers)
  • Fallen (Jailed Towers, Back to Basics, Legion)
  • Hazard (Jailed Towers)
  • Glitch (Jailed Towers, Legion)
  • Error (Jailed Towers)
  • Reaver (Boss Rush)
  • Living Experiment (Boss Rush)

All enemies in the Oops! All slimes! challenge map spawn with the Slime attribute due to the Oops all slimes! modifier.

The following enemies used to have Slime by default, but no longer do so:

  • Failed Experiment
  • Slime
  • Slime (Legacy)

The following enemy used to spawn with Slime, but did not have it by default:

  • Ghoul
  • Enraged
  • Breaker2
  • Necromancer
  • Hazmat
  • Armored
  • Speedy Boss
  • Hidden Boss

The following enemies could spawn with Slime in events, but did not have it by default:

  • Hidden (The Classic)
  • Korblox Warrior (The Classic)
  • Korblox Seeker (The Classic)
  • Korblox Soul (The Classic)
  • Slow Boss (The Classic)
  • Normal Boss (The Classic)
  • Guest (Pls Donate)
  • Cat (Pls Donate)
  • Korblox Seeker (The Hunt: Mega Edition)
  • Korblox Soul (The Hunt: Mega Edition)
  • Korblox Warrior (The Hunt: Mega Edition)

Update History

  • 3 May 2024 - v1.20.0
    • Slime added.
    • Bug: Slime prevents enemy abilities if they happen on death.
    • Bug: Slime Ghouls, Reavers and Living Experiments do not spawn a Slime on death.
  • 2 August 2024 - v1.27.0
    • Bugfix: Slime no longer prevents enemy abilities if they happen on death.
  • 8 May 2026 - v1.90.0
    • Bug: Tag under an enemy's health bar is now displayed as Slowed instead of using its own tag.
  • 5 June 2026 - V2.0.0
    • Bugfix: Tag under an enemy's health is now displayed partially fixed with the name has been reverted to Slime. Though the icon remains the same.
