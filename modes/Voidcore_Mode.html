Description

Voidcore mode is one of the two hardcore modes, being the most difficult mode in the entire game. It can only be played by using the center Hardcore Elevator or through the hardcore Matchmaking menu. Like Hardcore mode, Voidcore mode rewards Gems instead of Coins, but unlike Hardcore mode Coins can be earned upon successful completion of this mode. You need to first triumph Hardcore mode and be at least Level 50 to play this mode.

Cash is only gained if an enemy is killed, or in some cases, damaged by a specific amount of health. Additionally, the amount gained is a set amount of cash, which is not always equal to the enemy's health. It uses a slightly different method of distributing cash between players, as enemies split their cash between players, regardless of how much damage the player dealt to it. If, in a duo, one player does all the damage to an enemy, both players will receive 50% of the cash the enemy would normally give in solo. This means that in solo, you receive 100% of the cash when an enemy is killed, or it is damaged enough. With each additional player, this is reduced to 50% in duo and 33% If it is a decimal, it gets rounded up or down depending on the decimal value. If it is at least 0.5, it gets rounded up. If it is less than 0.5, it gets rounded down.

Consumables and Skills are disabled in this mode. Shrines also appears in this mode starting from Wave 11, re-appearing every 10 waves.

Rewards

The game calculates how many Gems and EXP you receive based on how many waves you survived and if you won a match. During periods of 100% more EXP (Friday – Sunday), any EXP earned is multiplied by 2x through the XP Boost modifier. The VIP gamepass also multiplies any EXP earned by 1.25x through the VIP Boost modifier. These two boosts are additive. These EXP bonuses multiply EXP after it has been multiplied by modifiers.

Any rewards that end in a decimal point is rounded down, no matter the first figure of the leading decimal.

Currently, rewards are calculated as:

Gems Reward Coins Reward EXP Reward Tower EXP Reward
250 ÷ (1 + [(50 ÷ Current Wave) - 1]^3) + 450 (Triumph Bonus) 1,000 (Triumph Bonus) 200 EXP ÷ (1 + [(50 ÷ Current Wave) - 1]) + 300 EXP (Triumph Bonus) 190 EXP ÷ (1 + [(50 ÷ Current Wave) - 1]) + 230 EXP (Triumph Bonus)

Wave Structure

In Voidcore mode, the formula for calculating wave bonus on each wave in is:

($350 + ($30 × Waves Completed)) ÷ Players

Depending on player count, the wave bonus is reduced using multipliers. These multipliers are:

Players Reduction per Player Total Reduction
Solo 0% 0%
Duo 5% 10%
Trio 6.7% 20.1%

The wave clear bonus does not appear in this mode.

Trivia

  • Voidcore mode is one of two only game modes to have a maximum player count of three, the other being Hardcore.
  • Voidcore mode is the first non-event game mode to have cutscenes.
  • The badge for beating Voidcore mode shares the same exact description as the badge for beating Hardcore mode before the rework.
  • Interestingly, a new Shrine can spawn on Wave 50 after defeating the Void Reaver and Void Caster, even though the game would technically be over by then.
  • Currently, triumphing Voidcore Mode sends out a global server message stating: "[Server] Player has silenced the void! Congratulations!". It will list every player and get slightly adjusted based on if its one or more players.
    • Voidcore mode is the second game mode to announce a global server message per triumph, with the first being Fallen Mode on the Hidden Wave.
