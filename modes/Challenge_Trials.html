Description

Challenge Trials is a difficult mode that can only be played through Matchmaking. It has a requirement of Level 40. The main gimmick of the mode is that every three hours, a different trial starts, which has a new modifier, map, and rewards. Upon successful triumph of this mode, the modifier that was active on that mode would be given to players to use on any match if this was their first time completing the trial for that modifier.

Cash is only gained if an enemy is killed, or in some cases, damaged by a specific amount of health. Additionally, the amount gained is a set amount of cash, which is not always equal to the enemy's health. It uses a slightly different method of distributing cash between players, as enemies split their cash between players, regardless of how much damage the player dealt to it. If, in a duo, one player does all the damage to an enemy, both players will receive 50% of the cash the enemy would normally give in solo. This means that in solo, you receive 100% of the cash when an enemy is killed, or it is damaged enough. With each additional player, this is reduced to 50% in duo, 33% in trio and 25% in quad. If it is a decimal, it gets rounded up or down depending on the decimal value. If it is at least 0.5, it gets rounded up. If it is less than 0.5, it gets rounded down.

The health of enemies in this mode scales with the player count, starting at two players. The increase is 10% in duo, 25% in trio and 40% in quad. It is applied after attributes, like Bloated, meaning they can affect the health of an enemy. The increase is not always the stated amount.

Consumables and Time Scale are both disabled on this mode regardless of the current modifier. However, Skills are enabled across all modifiers on this mode.

Trials

Challenge Trials have a unique mechanic of having a specific modifier be applied every three hours to it, which on top of what is stated dictates other things like if Skills are enabled or what map it is on. The following trials are available in this order:

  • Speedy Enemies, all enemies are Nimble, map set to Wrecked Battlefield and Skills are enabled.
  • Glass, base health is set to 1, map set to Stained Temple and Skills are enabled.
  • Quarantine, increases placement footprint of towers by 10, map set to Dusty Bridges and Skills are enabled.
  • Fog, tower range is reduced by 35%, map set to Winter Abyss and Skills are enabled.
  • Limitation Makes Creativity, tower placement limits are decreased by 50%, map set to Coral Deep and Skills are enabled.
  • Flying Enemies, all enemies become Flying after Wave 5, map set to Sacred Mountains and Skills are enabled.
  • Jailed Towers, a tower type is jailed every wave after Wave 5, map set to Night Station and Skills are enabled.
  • Exploding Enemies, enemies explode on death, map set to Wrecked Battlefield II and Skills are enabled.
  • Inflation, all prices are increased by 50%, map set to Cyber City and Skills are enabled.
  • Committed, towers cannot be sold, map set to Retro Zone and Skills are enabled.
  • Hidden Enemies, all enemies become Hidden after Wave 5, map set to Forgetten Docks and Skills are enabled.
  • Broke, income is reduced by 50%, map set to Medieval Times and Skills are enabled.
  • Healthy Enemies, all enemies are Bloated, map set to Four Seasons and Skills are enabled.
  • After this, the order is repeated starting from the first trial in this list.

Rewards

Rewards are only given out on triumph, which means losing on any wave gives 0 EXP and no rewards. During periods of 50% more EXP (Friday – Sunday), any EXP earned is multiplied by 1.5x through the XP Boost modifier. The VIP gamepass also multiplies any EXP earned by 1.25x through the VIP Boost modifier. These two boosts are additive.

Wave Structure

Currently, Challenge Trials has two wave bonuses, based on the current wave. Between waves 1 to 30, the wave bonus is calculated as:

$300 + ([Waves Completed - 1] × $100)^1.03

Between waves 31 and 40, it is calculated as:

$300 + ([Waves Completed - 1] × $100)^1.07

Depending on player count, the wave bonus is reduced using multipliers. These multipliers are:

Players Reduction per Player Total Reduction
Solo 0% 0%
Duo 5% 10%
Trio 5% 15%
Quad 10% 40%

Wave clear bonus is 40% in solo and 20% in duo or higher.

Trivia

  • Challenge Trials is the first game mode since Polluted Wasteland II to release with only Elevators, and Matchmaking had since been implemented for this game mode in V2.4.0.
    • When Challenge Trials was initially Elevators-only, it was likely done to expose more players to Elevators as the v1.75.0 update also upgraded them in addition to releasing Challenge Trials.
